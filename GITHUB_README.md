# Pause for Paws - Wildlife Corridor Safety

A web and mobile app that provides historical wildlife corridor analysis for driver safety awareness.

## Features

- Historical animal crossing corridor data analysis
- Risk level assessment based on past incidents
- Educational tool for driver awareness
- No real-time tracking or live location monitoring

## Important Disclaimer

⚠️ **This app analyzes HISTORICAL DATA ONLY**
- No real-time animal detection
- No live location tracking
- For informational and educational purposes only
- Should not be the sole basis for driving decisions

## Data Source

- Historical wildlife collision archives (2015-2024)
- Iowa animal crossing data analysis
- Public incident records

## Technologies

- JavaScript frontend
- Python backend
- Capacitor for mobile packaging
- Google Play Store deployment

## Installation (Web)

1. Clone this repository
2. Open `index.html` in a web browser
3. Or run the Python server:
   ```bash
   python server.py
   ```
   Then visit `http://localhost:8000`
